# Quy trình hướng dẫn ERP An Binh Foods

Tài liệu này hướng dẫn chi tiết từng bước thao tác cho nhân viên các phòng ban trong hệ thống ERP.

## Mục lục

| File | Áp dụng cho |
|------|------------|
| [`00-chung.md`](./00-chung.md) | **Tất cả nhân viên** — Chấm công, báo cáo, nghỉ phép, YC-CC, YC-SC, nhiệm vụ, kế hoạch, tăng ca, góp ý |
| [`01-chat-luong.md`](./01-chat-luong.md) | **Bộ phận Chất lượng** — Quản lý NV, đánh giá, bảng lương, điểm danh, quy trình |
| [`02-tong-hop.md`](./02-tong-hop.md) | **Bộ phận Tổng hợp** — Xử lý YCBG, tính báo giá, chi phí, quản lý khách hàng/NCC |
| [`03-kinh-doanh.md`](./03-kinh-doanh.md) | **Bộ phận Kinh doanh** — KH, YCBG, báo giá, đơn hàng, phản hồi, dashboard |
| [`04-ke-toan.md`](./04-ke-toan.md) | **Bộ phận Kế toán** — Hóa đơn, công nợ, tài sản, báo cáo thuế |
| [`05-thu-mua.md`](./05-thu-mua.md) | **Bộ phận Thu mua** — NCC, YC-MH, duyệt mua, đơn hàng |
| [`06-san-xuat.md`](./06-san-xuat.md) | **Bộ phận Sản xuất** — Máy móc, quy trình, đơn hàng SX, kho, YC-CC, báo cáo |
| [`07-ky-thuat.md`](./07-ky-thuat.md) | **Bộ phận Kỹ thuật** — Hệ thống máy, báo cáo HĐ, YC-SC, nghiệm thu |

## Cách sử dụng

1. Chọn file tương ứng với phòng ban của bạn
2. Tìm quy trình cần thực hiện theo mục lục
3. Làm theo từng bước từ trên xuống dưới

> Tài liệu này được xây dựng dựa trên mã nguồn và chatbot docs của hệ thống ERP.
